```bash
cd "Venda de ingressos - SDB"/frontend
python3 -m http.server 8000
```

## Passo 2: Abra o Navegador

Copie e cole no navegador:
```
http://localhost:8000/src/pages/index.html
```

## Se Não Funcionar

Abra o Console (F12) e procure por erros em vermelho.

Se tiver erro como `Failed to fetch`, verifique se o servidor está rodando:
```
python3 -m http.server 8000
```
